# Political regimes: countries × people — public review package

Status: local V-009 owner-review candidate; not deployed and not published.

The package supports SignalPair Episode 02, comparing annual political-regime
composition when each eligible V-Dem political unit counts once and when each
person with observed population counts once, 1973–2025.

Primary classification: V-Dem v16 v2x_regime_amb, Q0 three-state rule.
Population: V-Dem e_wb_pop through 2024 plus an audited World Bank WDI 2025
extension. Missing population is excluded, never treated as zero.

The analysis is descriptive, ecological, post-exploratory and non-causal.
Residence under a classified regime is not a measure of individual preference.

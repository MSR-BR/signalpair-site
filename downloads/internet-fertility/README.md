# Internet use × total fertility — public data package

Frozen source snapshot: World Bank WDI source 2, last updated 2026-07-13.

Files:

- `data-country-year.csv`: eligible entity-year panel used by the video; complete and missing pairs are explicit.
- `annual-association.csv`: annual country-level association results.
- `endpoint-movements.csv`: paired 2000→2024 endpoint movement categories.
- `analysis-summary.json`: machine-readable primary and sensitivity summary.
- `linear-band-medians.csv`: descriptive guide drawn in the approved video.

The unit is a country/territory-year. These files do not support individual-level or causal claims.

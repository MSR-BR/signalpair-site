# SignalPair — Methods & Sources

Public methodology hub for SignalPair, a YouTube channel that pairs real-world indicators and follows them through time.

The site documents the shared scientific workflow, source standards, missing-data rules, interpretation limits, and the evidence-page structure used for each approved episode.

## Publication policy

Deployments are manual. A reviewed candidate is published only after explicit human approval.
